its own version, README and tests, and goes into a project as a checked copy.**

## Kits

| Kit | What it does | State |
| --- | --- | --- |
| **ModelKit** | Blender models built by scripts (cars, game pieces, cards, buildings) with automatic inspection: no flickering faces, no holes, no hanging parts, smooth arches, lights built from parts | in use, first to publish |
| **TestKit** | Seeded laws (Python, JS, C#), mutation runs, branch coverage gates in CI, memory and handle checks over 20+ launches, test harnesses without visible windows | planned |
| **ReleaseKit** | Release and publishing scripts, a privacy check before every push, README header, descriptions and topics | planned |
| **QtKit** | The window part for PySide6 apps: themes, buttons with tooltips, properly dimmed disabled controls, combo boxes | planned |
| **WebAppKit**, **SoundKit** | Shared parts for web apps; procedural sound | planned |
| **WpfKit**, **MlKit**, **VideoKit**, **ModKit**, **AgentKit** | WPF apps, small neural networks, code-only videos, game mods, prompts for agents | planned |
