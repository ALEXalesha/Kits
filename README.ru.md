## Наборы

| Набор | Что делает | Состояние |
| --- | --- | --- |
| **ModelKit** | Модели Blender скриптами (машины, фигуры, карты, здания) с автоосмотром: без мерцания граней, без дыр и висящих частей, ровные арки, фары из частей | в работе, выкладка первым |
| **TestKit** | Законы с зерном (Python, JS, C#), мутанты, пороги покрытия по ветвям в CI, память и хэндлы за 20+ запусков, тесты без видимых окон | в плане |
| **ReleaseKit** | Скрипты выпуска и выкладки, проверка личного перед каждым пушем, шапка README, описания и темы | в плане |
| **QtKit** | Оконная часть для программ на PySide6: темы, кнопки с подсказками, правильно бледные недоступные, выпадающие списки | в плане |
| **WebAppKit**, **SoundKit** | Общее для веб-приложений; звук кодом | в плане |
| **WpfKit**, **MlKit**, **VideoKit**, **ModKit**, **AgentKit** | Программы WPF, маленькие нейросети, ролики кодом, моды игр, промпты агентов | в плане |
